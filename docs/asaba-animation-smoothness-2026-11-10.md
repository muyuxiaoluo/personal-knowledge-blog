# 浅羽动画流畅度改造与实测

## 定位依据

三份旧源 GIF 均为 24 帧、每帧 150 ms，总长 3.6 秒，原始采样约 6.67 帧/秒。旧输出 WebP 实测每份 116 帧、4.06 秒，帧间隔包含 30、36、37、38、100、180 ms。思考中的姿态停留是有意设计的，但运动部分的采样和定时切换不能充分利用高刷新率屏幕。

旧组件通过更换图片并从赋值时开始计时，未等待解码完成；浏览器的图片播放时钟、动作结束定时器、鼠标跟随的绘制时钟彼此分离。

## 当前实现

- 从原始 GIF 和关键姿态重新生成等间隔的 60 Hz 图集，使用双向光流和迭代逆映射处理曲线轮廓，避免沿用旧补帧结果再次插值。
- `AsabaMotionClock` 使用同一个绘制时间推进动作。首帧解码完成才开始；未来帧未就绪时保留当前画面；隐藏后恢复不计入离屏时间；上一动作明确画出复位帧后才切换。
- `AsabaMotionRenderer` 使用一个 GPU 网格绘制调用；按实际 `requestAnimationFrame` 节奏混合相邻的 60 Hz 姿态。头部跟随、呼吸、发梢摆动按同一时钟连续变形，脚底区域固定。它们是图像的分区网格形变，未声称具有完整的三维骨骼或遮挡重建能力。
- 眨眼只合成脸部区域，保持身体和头发一致；稳定待机使用同一张站姿图，不循环整张重新绘制的人物图。
- 每页 24 帧，单页 1536×1280。运行时只保留站姿、当前页、下一页以及至多一页候选动作，旧页立即释放；不预解码所有动画。
- 系统减少动画或关闭自然待机时，停用循环绘制并显示站姿。组件销毁时中止加载、取消绘制，释放纹理、缓冲和绘制程序。

## 实际 Tauri 窗口测量

在现有 Windows Tauri 开发窗口测试，不使用普通浏览器替代。开发探针轮播七个动作、累计运行 96 秒，并包含主气泡收起、重新展开。

| 指标 | 观察值 |
| --- | --- |
| 15 秒时绘制调度节拍 | 240.0 Hz |
| 44 秒时绘制调度节拍 | 239.9 Hz |
| 96 秒时绘制调度节拍 | 239.5 Hz |
| 滚动采样窗口内第 95 百分位调度间隔 | 4.3 ms |
| 滚动采样窗口内超过 33.5 ms 的调度间隔 | 0 |
| 动作运行中的资源停等 | 0 |
| 动作采样跳帧 | 0 |
| 最大异步解码及上传耗时 | 48.7 ms，提前准备，未造成资源停等 |
| 观察到的页缓存数量 | 3，含站姿 |

以上是应用绘制回调节拍和播放时钟采样，并非外部仪器测量的显示器扫描频率。姿态资源仍为 60 Hz；其间通过纹理混合和连续网格运动更新画面。结果不代表高负载游戏下的 GPU 表现。

探针只用于开发验证，正常界面不展示。开发模式可通过 `asaba-motion-probe` 窗口事件启停，或 Ctrl+Alt+Shift+F8。它不会读取业务数据或调用模型。

## 检查

- 播放时钟、绘制生命周期及心情策略的 11 项相关测试通过，覆盖解码等待、隐藏恢复、队列合并、复位、重复请求、120 Hz 帧间混合、关闭/恢复绘制和纹理释放。
- 七个动作验证为等间隔 60 Hz，所有纹理页存在，解码后的动作首尾透明度一致。
- 前端类型、共享控件检查和生产构建通过。

素材中动作本身的姿态和遮挡仍取决于原始绘制；提高绘制节拍不等于创造出正确的新姿态。

实机测量之后又单独补制了 48 个连续原始画面的转身 GIF，用于替换旧大角度姿态间存在重影的转身。新资源通过图集完整性与首尾一致性检查。

| 操作 | 结果 |

自然待机开关已恢复测试前的开启状态，心情气泡偏好保持不变。本轮补验没有修改动画实现，也未重复此前已经完成的整套性能采样。

## 转身改为原地小舞步

用户反馈转身时头部显著变大，且动作缺少舞蹈感。源图虽然按全身高度和脚底对齐，不同方向的头身比例仍有差异，继续调全身缩放无法同时固定头部和身高。

- 停用旧转身 GIF 及其纹理页，构建时排除 `spin-*.webp`。保留内部 `spin` 标识供现有待机和右键入口使用。
- 动作改为 4.2 秒的小舞步：左右交替点步、身体随节拍轻摆，配合手臂和裙摆，开头渐入、结尾渐出到同一站姿。人物窗口保持原位。
- 全程使用同一张站姿纹理，头部在像素坐标中只做刚性旋转和平移；舞步期间关闭原待机网格运动，避免变形叠加。舞步由实际绘制节奏连续计算，不增加图片序列或模型调用。
- 修正浮点累计导致动作末尾略早于终点的问题，结束姿态精确回到站姿。

15 项相关测试通过，新增覆盖头部旋转尺寸不变、双脚交替承重、活动范围、精确复位、仅加载站姿纹理及关闭动画后停止绘制。类型和共享控件检查通过。

在真实 Windows Tauri 开发窗口重新加载后，通过右键触发并分时查看舞步中段与结束姿态：人物始终保持正面的小幅节拍动作，头部未再出现旧转身时的放大，结束回到站姿。验证了自然待机关闭时静止、开启后恢复，最后恢复开启并收起设置。此前热更新保留了已有绘制实例，实机复测使用完整页面重新加载确保读取新清单。未重复之前的整套刷新率采样。
