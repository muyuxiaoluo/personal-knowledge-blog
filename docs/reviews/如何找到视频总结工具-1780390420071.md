# 如何找到视频总结工具？

## 问题
对B站的一些视频进行观看后写读后感，为了节省时间，需要找到能够总结视频的项目。

## 判断
选择 qwen 作为视频理解分析的工具。

## 理由
- 首先考虑了开源项目，例如 bilinote，但发现操作略显复杂，且 DeepSeek 不是多模态模型，无法进行视频理解。整体而言，bilinote 更倾向于是从视频中提取要点然后形成结构化输出（例如发布到小红书格式、博客格式等），虽然也可以进行详细分析，但需要多模态模型的 API，于是暂且作为备选方案。
- 还有例如 biligpt 等项目，要么需要付费，要么操作复杂不适配。
- 考虑到大模型本身就有视频理解能力，于是想到 qwen 和 gemini，进行尝试后，最终选择 qwen，因为本身任务要求的读后感并不要求对视频很高的理解，只需要概括理解就行。

## 适用范围
对B站视频写读后感，不要求高理解深度。
