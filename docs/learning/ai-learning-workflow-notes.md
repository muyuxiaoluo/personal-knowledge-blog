# AI 辅助学习工作流笔记

## 当前目标

建立一套适合自己的课程、视频和资料整理流程。

第一版不追求自动化，只追求稳定记录：

- 输入来源是什么？
- 我希望得到什么输出？
- AI 的结果是否能帮助复习？
- 哪些内容需要人工验证？

## 当前假设

对学习来说，工具只是提高效率或上限，真正决定效果的是输入质量、输出要求和复习动作。

## 待测试问题

- B站学习视频是否优先走“字幕提取 + AI 总结”？
- 课堂录音是否继续使用豆包作为低门槛方案？
- 输出格式是否应该固定为“核心观点、例子、疑问、可复习问题”？
