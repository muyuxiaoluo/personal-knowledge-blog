# 投入提醒与记录修正

在“今日行动”中开始投入后，默认每 45 分钟在 Windows 桌面弹出一次提醒。通知以工作台自己的名称和图标显示，开发调试版也使用独立的通知身份。提醒通知会保持显示，直到用户处理或关闭。

Windows 通知中可以直接点击“继续投入”或“现在暂停”，这两个操作无需打开工作台。点击“刚才已结束”才会打开实际结束时间的修正入口。旧通知只关联原本的那段投入，不会暂停后来开始的新投入。应用内保留待确认提示，便于回到工作台后补处理。

提醒在桌面应用运行期间生效，包括最小化或收起到托盘。Windows 禁用系统通知或通知发送接口失败时，改用独立的 Windows 原生提醒弹窗；主窗口保持最小化或隐藏，无需更改系统通知设置。原生弹窗同样支持继续、暂停和修正结束时间，同时只保留一个提醒弹窗，避免反复叠加。系统通知已开启时，其显示仍受 Windows 勿扰设置影响。应用完全退出后不发送提醒，再次启动时沿用未结束投入的恢复流程。

可以在“今日行动 → 投入记录”点击“发送 Windows 测试提醒”，5 秒后发送不影响业务记录的测试通知。这期间可以切换到其他窗口或最小化工作台，检查后台通知是否正常弹出。

忘记暂停时，点击顶部计时条的“刚才已结束”，选择 10、30 或 60 分钟前结束，也可以填写实际结束时间。保存后会暂停投入，并按实际时间记录。

在“今日行动”右上角打开“投入记录”，可以修改已结束记录的开始、结束时间，或确认删除误记的记录。修改与删除会更新累计投入，并进入已有同步队列。正在进行的记录需要先暂停才能作为历史记录修改或删除。

“投入记录”顶部可以选择每 15、30、45、60、90 分钟提醒，或关闭提醒。提醒设置保存在当前设备。列表初次显示最近 50 段，可以继续加载至最近 2000 段。

提醒不会自动暂停，也不会根据键盘鼠标空闲情况扣除时间。
