# 个人博客建设：项目档案 v1.1

## 项目类型

主线任务

## 目标

建立一个本地优先的个人知识库博客，把经验、工具评测、学习方法、提示词模板、思考随笔和长期项目集中沉淀。

## 当前阶段

v1.1：视觉与内容体验升级。

完成标准：

- 本地能启动。
- 首页像个人知识库控制台。
- 知识树是内容分类和浏览的唯一入口。
- 有草稿区和弱化的示例存档。
- 普通文章顶部显示元信息。
- 搜索可用。
