# 我的个人知识库为什么不是普通博客

普通博客更像是对外表达，而这个知识库首先是面向自己的长期记录系统。

它的目标不是证明我已经想明白了，而是留下思考过程，让以后的自己能看见：当时遇到了什么、为什么这样判断、后来是否仍然有效。

## 我希望它解决的问题

- 防止同一个坑反复踩。
- 把零散经验整理成可复用模板。
- 记录工具、方法和判断随时间的变化。
- 在信息很多的时候，帮我聚焦当前真正要推进的问题。

## 它应该像什么

它可以有一点“人生攻略库”的感觉：

- 主线任务：长期成长方向。
- 支线任务：具体实验和项目。
- 经验值：复盘、模板、清单、判断标准。
- 奖励：更稳定的行动、更少的焦虑、更清楚的选择。

但这种表达只是一种帮助自己行动的叙事。真正重要的还是内容是否清楚、是否能复查、是否能在以后帮我少走弯路。

## 当前原则

- 内容优先于外观。
- 先写真实经验，再完善系统。
- 结论允许更新，不把临时判断当成永恒答案。
- 分类按用途，不按领域硬分。
