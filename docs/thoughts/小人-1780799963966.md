# 小人

曾听人说，知识是一种诅咒。伊甸园里那条蛇蜿蜒而来，带来的不单是果实的甘美，更是分别善恶的傲慢——知道得愈多，便愈容易觉得自己站在了高处，看着尚在匍匐的人影，心里悄悄生出一层薄薄的霜。如此说来，人那自诩努力的一生，也许就是被知识不断加冕、又不断禁锢的一生。这诅咒并非让人痛苦于无知，而是痛苦于自以为知；并非痛苦于黑暗，而是痛苦于举着一星烛火，便以为拥有了整个太阳。

我曾经那样热衷于用自己的道理去开解别人，将那一点微末的见识，精心包裹成劝慰的模样，一遍遍地说给人听。那时我以为自己是在布施甘露，如今想来，那姿态里藏着深不见底的傲慢。我的话语，究竟是想要扶起一个溺水的人，还是贪恋着他抬起头来仰望我时，那一瞬的错觉？这念头从前只在良心的暗处明明灭灭，如今却烧灼起来。那时我的心里，其实悄悄蹲着一只小兽，披着助人的皮毛，却在每一次对方颔首时，餍足地舔舐自己的爪尖。所以，当人家拒绝时，错愕与难过便汹涌而至，愧疚与自责却姗姗来迟，像一场稀稀落落的细雨，浇不灭根底的燥热。

言语一旦多起来，往往不是为了照亮什么，而是为了掩盖什么。那些漂亮的道理从舌尖滚落，像肥皂泡在阳光下闪着炫目的光，飘到对方头顶便碎了，什么也没留下，只溅了人家一脸黏腻。真正的安慰，或许从来不在唇舌之间，而在弯下腰的那一刻——在那沉默的、将肩膀与对方齐平的时刻。

古人云：

> 人之患，在好为人师。
>
> 君子论迹不论心，论心世上无完人。

我只觉自己离君子二字，实乃相去之远。论心，我有太多见不得光的缝隙；论迹，那缝隙里更是寸草不生。这让我蓦地想起一个遥远的下午，那时的我还是个身形和心智都未长成的孩子，被喊到老师办公室，因为一场打架而受责。班主任冷冷地打量着我，嘴角挂着一丝讥诮：

> “背后骂人了？”

“那也是他先动的手！”我脸上写满了不服气。

她满脸不屑，轻飘飘甩出一句话，像一枚生锈的钉子，楔进我尚薄的少年时代。

> “小人！”

我张了张嘴，辩驳的气流堵在喉间，终是无声。思绪在脑中轰然炸开，又缓缓归于沉寂。死寂里，一个标签啪地贴在皮肤上，起初火辣辣地疼，后来竟与皮肉长在了一起。彼时的我以为，那不过是对一个顽劣孩童的训斥。直到多年以后才悚然发觉，那声“小人”仿佛一粒种子，深深埋进了我后来的人生。

“小人”，真的就只是小人吗？

如今我的身量早已抽条，年龄也冠上了“大人”的名头，可那件无形的长衫，我却始终没有脱下来。孔乙己的长衫，是读书人最后的体面，也是最深的枷锁。我口口声声说不拘学历、不存歧视，可那长衫底下，依然藏着一双掂量人的眼睛。这长衫早已不是蔽体的布料，而是我用读过的书、晓得的理、懂得的典，一针一线缝制出的罩衣。披着它，我走得四平八稳，仿佛真就成了一个温润的大人。可只要一阵风掀起衣角，底下那只小兽依旧蜷在那里，眼神闪烁。

成长的叙事总有光明的尾巴，像童话里王子终于找到了公主。可我没有找到什么。我只是看见了自己——那个在老师办公室里被叫做“小人”的孩子，和后来这个学会了把傲慢藏好的“大人”，其实并没有什么不同。

或许也有着不同：那时候的我认了，现在却还在找各种理由与借口，妄想挣脱。

这大约就是我所有聒噪的根源。所有见不得光的东西，终要被摆到太阳底下来。

可太阳底下的事，反而容易干净。

更可悲的是，我常耽于这种反省本身。痛哭流涕地剖析自己，言辞如瀑布倾泻，仿佛只要把罪过说尽了，罪便消融在声音里了。然而月亮升起，第二日照旧披上长衫，照旧在交谈中不动声色地量一量对方，照旧把言语当作行动，把忏悔当作功德。这不过是另一种精心修饰的聒噪——像夏日的蝉，把壳蜕了一半，便急于向世界宣告蜕变，身子却还牢牢粘在旧壳里，一步未曾挪动。

> 毋意，毋必，毋固，毋我。

这四个词里，最后一个恰似一把极小的刀，直直剖开胸口。我的那么多烦恼、傲慢、自怜，哪一桩不是围着那一个小小的“我”在打转？真正的“大人”是什么——不是身高的拔节，亦非学历的堆叠，而是懂得把自我放得低些，低到尘埃里去，去体谅，去理解，去行动。行动，这个词像一块沉甸甸的石头，压住了所有浮泛的口沫。夸夸其谈的安慰，若没有行动做底，不过是一阵风，吹过便散；口口声声的忏悔，若没有改变接续，不过是一场精巧的自娱。

**行，远胜于言。迹，终明于心。**

> 君子欲讷于言而敏于行。

我从前说得太多，做得太少，如同鲁迅所讥的“做戏的虚无党”——锣鼓喧天，散了场，一切照旧。

只希望能更加正视自己，做一个知行合一的人。
