# 折中的艺术？中庸的错误！

##
事情发生在一个雨夜。下课出来，天色已晚，雨丝淅淅沥沥，偏偏我今天没带伞。为了少淋一会儿，我扫了辆自行车骑出校门，可刚到门口，雨竟停了。心里一下子松下来，便也不那么着急。站在路旁犹豫了好一阵，盘算着回家的三种选择：

等二十分钟后的公交末班车，上车还要再坐十五分钟；

直接打车，十块钱左右，最快；

先坐半程公交，再骑一段车回去，总共四块钱，耗时大约二十五分钟。

既不想在雨里枯等那么久，又舍不得多花那十块钱，我暗自得意于自己的“精明”——时间省了些，钱也省了些，岂不两全？于是选了方案三。

然而，这才是最坏的结局。

从公交车上下来，眼前第一个难题是：没有电瓶车。路上零星散着几辆自行车，我都瞧不上眼；好不容易遇到一辆电瓶车，又嫌它太过破旧，不愿骑。就这么走了一大截路，终于找到一辆还算顺眼的电瓶车，可刚扫开，天空竟又落起雨来。我慌忙骑车想逃，可人哪跑得过雨？半路上便被淋得透湿，狼狈不堪，地面湿滑，还差点连人带车侧翻过去。到了最后一段路，只能把书包顶在头上勉强挡雨，可书还是被洇湿了。

回到家，我不禁反问自己：那个我自认为最划算的选择，为何偏偏成了最糟的结果？

若我当时安心等公交，就算等得再久，至少不会淋得这般凄惨；若我索性打车，早已安然到家，压根碰不上那场雨。可偏偏选了那条看似折中、实则最不合时宜的路。

生活中，是否也常常如此？没有争第一的勇气，也没有甘居末流的底气，只是在中间地带忙忙碌碌，左右摇摆。而中间的位置，往往最不被人记住——像墙头草，看似两边都占，实则两边都不靠，到头来只落得一场空叹。

晾书的时候，我盯着那些皱起来的纸页发呆。水把每一行字都泡得晕开了边，像是写字的那个我曾经信誓旦旦划下的句号，如今全变成了省略号。

我忽然在想，当时站在公交站台的那个我，到底在害怕什么？

不是怕冷，也不是怕花钱。那十块钱和二十几分钟，放到一生的尺度里，根本不算什么。真正让我反复权衡、左右摇摆的，是一种更隐秘的恐惧——我怕选错。

等公交，怕浪费时间；打车，怕显得奢侈；骑车，怕半路下雨。每一种选择都自带一种“后悔的可能性”，而我所谓的“折中方案”，不过是用数学上的平均，给自己造了一个幻觉：只要我各取一半，就等于没有把全部筹码押在任何一边，那么无论哪边出问题，我都不至于输得太惨。

可生活从来不按这种逻辑运行。它不认你的加权平均，不认你的风险对冲，它只认你站在哪一条路上，然后把你从头到脚淋透。

我突然觉得，我们这一生都在做类似的事。选专业的时候，选一个“好找工作又不算太难”的；选工作的时候，选一个“钱不算少但也别太累”的；选人的时候，选一个“差不多合适”的。我们用各种温和的词汇包装它——稳妥、平衡、务实——但说到底，不过是在害怕。怕选了A就错过B，怕走得太远就回不了头，怕孤注一掷之后发现押错了注。

于是我们把自己安放在一个“不会被彻底否定”的位置上，哪边都沾一点，哪边都不完全属于。可这种位置最大的陷阱是：它给你一种“我掌控了一切”的错觉，直到意外降临，你才发现自己连一条可以死守的退路都没有。

那晚最让我难过的，不是被雨淋湿，而是我发现，我连“认命”的勇气都没有。等公交的认了等，打车的认了花，而我选了第三条路，却一路上都在骂骂咧咧——嫌车破、嫌雨大、嫌路滑。我选了一条自认为最“聪明”的路，却走出了一个最不体面的姿态。

后来我想，也许人这辈子最重要的能力，不是算出哪个选择最优，而是选完之后，能够坦然地说一句：就它了，我认。

认输也好，认亏也好，认命也好。那个“认”字里，有一种笨拙的、结实的勇气。它意味着你终于接受了一个事实：生活从来不给标准答案，你只能在有限的信息里押下一注，然后承担它所有的后果，好的坏的，晴朗的或下雨的。

书晾干了。纸虽然皱了，但字还是那些字。我合上它，想着，往后别再做那种“两边都够一够”的事了。要么等，要么走，要么干脆淋一场。至少淋雨的时候，你是真的在路上。
