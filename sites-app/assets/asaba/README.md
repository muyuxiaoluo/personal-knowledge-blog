# 浅羽待机动画素材

`source-48.png` 是通过 GPT 网页生图、以原有 `desktop/asaba.webp` 为参考生成的 8 列 × 6 行图集。一次请求包含四段连续动作，每段 12 张关键帧：眨眼、思考、伸懒腰和转身。保留原始素材便于以后重新处理。

`desktop/asaba-animation/` 保留第一版对齐后的图集和 30 帧资源。当前运行时改用 `desktop/asaba-motion/` 的 60 帧分块纹理，由 `scripts/build-asaba-motion.py` 从原始姿态重新制作。旧 `keyframes.webp` 是对齐后的制作输入，`preview.webp` 是旧版预览；旧动画文件不再作为播放器资源导入。

处理时所有帧共用一个缩放比例，以脚底中心和基线对齐，避免逐帧按包围盒缩放导致人物忽大忽小。透明边缘按主体连通区域清理。每个动作首尾使用相同的中性站姿，关键帧之间用双向光流补成约 30 帧/秒，颜色与透明度采用同一组形变。思考和伸展有短暂停留，眨眼之间留有间隔。补帧属于图像插值，复杂转身的遮挡仍受关键帧质量限制。

重新处理需要 Python、Pillow、numpy 和 opencv-python-headless，仅作为素材制作工具，不是应用运行依赖。

```powershell
python sites-app/scripts/build-asaba-animation.py sites-app/assets/asaba/source-48.png sites-app/desktop/asaba-animation
```

## 本次生图提示词

请直接生成一张用于 Windows 桌宠的透明背景逐帧动画精灵图，不要只给文字。参考附件中的原创角色浅羽，严格保持同一白发蓝眼少女、月牙发饰、长发小辫、白蓝裙子、兔子挂饰、原有 Q 版头身比例和画风。

输出一张 2048×1920 的 PNG，严格等分为 8 列×6 行，共 48 个格子，每格 256×320，无边框、无格线、无文字、无数字、无水印、无场景、无地面阴影，背景真正透明。每格只画一个完整人物，头顶和脚底不裁切。所有格子摄影机完全固定、身体尺度完全一致、脚底在各格相同位置，正面站立时角色从呆毛到脚底约 285 像素高、脚底 y=305，左右中心 x=128。不能为了抬手而把人物整体缩小，不能每一格重新构图。

这是一张连续动画的 sprite sheet，而非不同姿势的展示卡。按从左到右、从上到下的 48 帧顺序，分成四段连续动画，每段 12 帧，每段第 1 帧和第 12 帧都回到同一个正面中性站姿。第 1 段（帧 1 至 12）自然呼吸，发梢轻晃，眼睛缓慢眨一下再睁开。第 2 段（13 至 24）从同一站姿渐渐抬一只手托下巴思考，微微歪头，停留后平滑放手复位。第 3 段（25 至 36）从同一站姿渐渐抬起双手伸懒腰，轻轻闭眼，再慢慢放手复位，脚始终原地。第 4 段（37 至 48）原地自然转一圈，包含正面、四分之三侧面、侧面、背面、另一侧和正面的一系列真实中间姿势，脚底位置不漂移。每个动作都必须画出逐渐变化的中间帧，前后两格只有微小动作变化，保持五官、服饰结构和体积，不要复制少量终点姿态充数。请优先保证连贯性和比例一致。

实际生图输出为 1295×1214，仍为 8×6 排列，制作脚本按真实尺寸分格，再输出统一的 256×320 画布。
