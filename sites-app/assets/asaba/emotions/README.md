# 浅羽的 GIF 互动动作

本批按用户指定，通过 GPT 网页的 GIF 生成功能制作，参考桌宠的 `desktop/asaba-animation/neutral.webp`。前三份源文件均有 24 帧、每份约 3.6 秒；后续为改善转身连续性另补了 48 帧 GIF：

| 源文件 | 动作 | 使用场景 |
| --- | --- | --- |
| `cuddle.gif` | 抱起小白兔玩偶、蹭一下，再放下 | 安静陪伴、工作时偶尔的小回应 |
| `cheer.gif` | 握拳鼓劲、微笑、略微害羞 | 摸头、新委托结果和右键互动 |
| `sleepy.gif` | 揉眼、抱兔、轻轻点头后重新打起精神 | 夜间心情与右键互动 |
| `spin.gif` | 48 个逐渐转身的画面，正面经过背面再返回 | 历史素材，因头身比例变化已停用 |

`desktop/asaba-emotions/` 保留上一版 30 帧透明 WebP，当前图集动作使用 `desktop/asaba-motion/` 的等间隔 60 帧分块纹理。GIF 的调色板、浅色背景及人物比例在制作时处理，所有帧采用同一缩放比例，按脚底位置对齐。首尾与固定站姿衔接，用同一组双向光流及迭代逆映射处理颜色和透明度。统一全身高度仍无法消除源图内部的头身比例差异，因此 `spin.gif` 及旧 `spin-*.webp` 不再参与生成或打包。当前 `spin` 使用 `asaba-dance.ts` 的 4.2 秒原地小舞步，始终使用同一张 `neutral.webp`，连续驱动点步、摆臂、身体和裙摆，头部只旋转和平移。制作命令如下；`--only spin` 只更新舞步清单及统一站姿。

```powershell
python sites-app/scripts/build-asaba-motion.py
```

工具依赖沿用上一批素材的 Pillow、numpy、opencv-python-headless，均只用于制作素材。台词、冷却规则和右键轮换顺序在 `desktop/asaba-personality.ts`，运行时不生成文字、不合成闲聊语音。
