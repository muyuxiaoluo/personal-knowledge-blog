## Default Permission

交易通知采集设置、提醒授权与补全入口

#### This default permission set includes the following:

- `allow-initialize`
- `allow-status`
- `allow-configure`
- `allow-open-access-settings`
- `allow-request-notifications`
- `allow-test-reminder`
- `allow-open-reminder-settings`
- `allow-take-open-request`
